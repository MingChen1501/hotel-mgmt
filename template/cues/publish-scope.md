PUBLISHING: publish a branch/PR only within the owner-authorised workflow. Available credentials, an existing remote, or an associated PR do not by themselves authorise publishing. Explicit local-only/review-only/do-not-publish restrictions always win. Never create a new repository or publish outside the project without explicit owner authorisation.

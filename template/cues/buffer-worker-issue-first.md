OWNER RULE: when the owner describes a new task, bug, or enhancement in chat, first spawn a dedicated buffer worker (issue creation only) that files GitHub issue(s) with context, scope, acceptance criteria, one type label and one risk label, in English. The buffer worker never implements, reviews, pushes, opens PRs, or merges. The orchestrator never files owner-task issues itself and never starts implementation first. The buffer slot is exempt from the pool.
